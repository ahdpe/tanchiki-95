# Танчики — Назад в 95

Браузерная игра в духе приставочных танчиков 1990-х: комната школьника, 13 октября 1995 года, стол, телевизор и ты.

**Играть:** https://ahdpe.github.io/tanchiki-95/

- 35 собственных уровней, режимы 1 и 2 игрока, 2D и 3D-камера.
- Работает в браузере на компьютере и телефоне, ничего устанавливать не нужно.
- Сделано с помощью Claude Opus 5.5, Blender, PlayCanvas, TypeScript и Vite.

Автор: [@Andrey_Os](https://t.me/Andrey_Os)
